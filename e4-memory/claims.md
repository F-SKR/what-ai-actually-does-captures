**Evidence types.** `capture` = a value read from a committed capture.
`own-measurement` = our own run (pending capture keys), the run's design as fixed in
the experiment plan, or arithmetic on capture values. `paper` = a paper, a vendor
page (Anthropic's engineering post and API docs, Chroma's report, the Qwen model
card) with URL and section; the lane's evidence types have no separate `vendor`, so
vendor pages are typed `paper`. `code` = llama.cpp at the pinned commit, mlx-lm, or a
repo file. `series-structure` = the series as declared by the operator.

**Spoken rounding.** llama.cpp reports the KV cache in MiB; 288 MiB is spoken "about
three hundred megabytes" (302 MB), 9,216 MiB "nine gigabytes" (9 GiB) and 4,608 MiB "four
and a half gigabytes" (4.5 GiB), the words series 1 Part 4 used. The exact MiB values go
on screen. Context
sizes are spoken rounded: 2,048 tokens as "two thousand", 65,536 as "sixty-five
thousand", 32,768 as "about thirty-two thousand". The exact values go on screen.
